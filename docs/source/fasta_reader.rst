Класс FastaReader
=================

Класс ``FastaReader`` предназначен для последовательного чтения
биологических последовательностей из FASTA-файлов.

Для каждой корректной FASTA-записи создаётся объект класса ``Seq``.
Чтение реализовано с использованием генератора, что позволяет
обрабатывать записи по одной, не загружая весь файл в память.

# FASTA Project

Учебный проект на Python для чтения, проверки и обработки биологических последовательностей в формате FASTA.

Программа поддерживает работу с нуклеотидными и белковыми последовательностями, определяет их длину и предполагаемый тип алфавита, а также позволяет последовательно обрабатывать записи из Multi-FASTA-файлов.

## Возможности

- Чтение FASTA-файлов с одной или несколькими записями.
- Создание объектов `Seq` для хранения биологических последовательностей.
- Получение длины последовательности и её строкового представления.
- Определение предполагаемого типа алфавита: нуклеотидный, белковый или неизвестный.
- Последовательная обработка FASTA-записей с использованием генератора.
- Проверка некоторых ошибок формата FASTA и вывод сообщений об ошибках.

При определении алфавита приоритет отдаётся нуклеотидной последовательности, если набор символов допускает неоднозначную классификацию.

## Требования

- Python 3.9 или новее.
- FASTA-файл для обработки.

Для запуска основной программы установка дополнительных библиотек не требуется.

## Установка

Скачайте исходный код проекта с GitHub через **Code → Download ZIP** и распакуйте архив либо клонируйте репозиторий с помощью Git.

Перейдите в корневую папку проекта:

```bash
cd fasta_project
```

## Запуск

Выполните команду:

```bash
python3 main.py
```

После запуска программа запросит путь к FASTA-файлу:

```text
Введите путь к fasta-файлу:
```

Укажите путь к файлу, например:

```text
data/example.fasta
```

Для каждой прочитанной FASTA-записи программа выводит:

- заголовок последовательности;
- первые 100 символов последовательности;
- полную длину последовательности;
- результат определения типа алфавита.

При обнаружении предусмотренных ошибок программа выводит соответствующее сообщение.

## Основные классы

### Seq

Класс для хранения одной биологической последовательности и её FASTA-заголовка.

Основные методы:

| Метод | Назначение |
|---|---|
| `__str__()` | Возвращает строковое представление FASTA-записи |
| `__len__()` | Возвращает длину последовательности |
| `alphabet()` | Определяет предполагаемый тип алфавита |

### FastaReader

Класс для чтения FASTA-файлов.

Метод `fasta_reader()` реализован как генератор, который последовательно создаёт и выдаёт объекты `Seq`, не загружая весь FASTA-файл в память.

## Тестирование

Проведено 10 проверок, включая обработку одиночных FASTA-записей, Multi-FASTA-файлов, пустых строк и некорректных входных данных.

Все проведённые тесты завершились со статусом **PASS**.

Подробные результаты представлены в файле [TESTING.md](TESTING.md).

## Документация

Документация классов создана с использованием Sphinx и темы Furo. Она включает описание атрибутов, методов, параметров и исключений, а также UML-диаграмму классов.

Для локальной сборки документации установите зависимости:

```bash
python3 -m pip install sphinx furo
```

Из корневой папки проекта выполните:

```bash
sphinx-build -b html docs/source docs/build/html
```

Откройте файл `docs/build/html/index.html` в браузере.
